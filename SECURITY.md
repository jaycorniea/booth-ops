# Security

Do not file public issues that include volunteer names, phones, emails, or other personal data.

Email security reports to the instance operator. Placeholder: `security@example.org`.

Production must set `ADMIN_PASSWORD`, `DAY_CAPTAIN_PASSWORD`, `VOLUNTEER_PORTAL_PASSWORD`, `ON_CALL_SIGNUP_PASSWORD`, and `VOLUNTEER_SIGNUP_PASSWORD`. The app refuses to start in production if they are missing.
